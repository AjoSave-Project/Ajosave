# Nigerian Pidgin (Naija) Translation Reference

## Notes on Nigerian Pidgin

1. **Flexibility**: Pidgin is very flexible and can mix with English. Many technical terms are kept in English.
2. **Context**: Some phrases can be translated multiple ways depending on context.
3. **Formality**: Pidgin is generally informal, so formal business terms often stay in English.
4. **Regional Variations**: Pidgin can vary by region in Nigeria. This reference uses widely understood phrases.
5. **Technical Terms**: For technical/financial terms, it's often better to keep English or provide both.

## Recommendations

For the AjoSave app, consider:
- Using Pidgin for common UI elements and actions
- Keeping financial/technical terms in English for clarity
- Providing tooltips or help text for complex terms
- Testing with native Pidgin speakers
- Being consistent with terminology throughout the app
